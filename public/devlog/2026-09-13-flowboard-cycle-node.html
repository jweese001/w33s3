FlowBoard's Cycle Node Gets Real

September 13, 2026

This week was a very FlowBoard week: the Cycle node moved from idea to shipped feature, with the web app and desktop app landing together and a second pass right behind it. The short version is that FlowBoard can now take a character reference, help me review a starting pose before spending video money, generate motion, key the result, and feed the selected frames back into the same graph as reusable sequence layers.

The most important design choice was cheap before expensive. A still pose is the place to catch bad anatomy, wrong framing, or a prompt that misunderstood the action. If I can reject a three-armed start pose at image cost, I do not have to discover it after paying for a video clip. That is why the Cycle work included a pose inspector modal, in-place prompt editing, regeneration, and a pinned approved pose before the video run.

The follow-up work was where the feature started to feel practical instead of merely possible. I added reference sequences as animated comp layers, made scrubbed sequence frames available to generation, persisted sequence frames in storage, and added a full comp inspector with playback, stepping, and export controls. I also moved GIF encoding into web workers after the main-thread encoder froze the UI at real composition sizes, and tightened exports so they say where files land.

The edge cases were the work

A lot of the week was less glamorous but more important: hardening imported project values, handling camera/shot preset drift, cleaning up comp export controls, and improving chroma-key output with automatic despill and matte-edge erosion. The green-screen problem was especially concrete: the background was easy to key, but green spill baked into the character edge needed a narrow edge-only pass so it would not eat real green wardrobe.

I wrote more detail in the FlowBoard Blog, especially Cycle Node Build Notes. Next, I want to keep pushing this from “animation works” toward “animation is comfortable to direct”: better defaults, clearer review points, and fewer places where the graph makes me remember what the graph could remember for me.
